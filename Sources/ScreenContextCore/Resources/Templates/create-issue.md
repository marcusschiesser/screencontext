Create an issue for the problem demonstrated below.

Use the source recording, keyframes, and transcript to understand the problem and as evidence. Build a concise issue with a clear title, a one-paragraph summary, numbered steps to reproduce the demonstrated behavior, expected versus actual results, and any error messages or relevant context shown in the material. Keep every claim grounded in the provided material.

Use the actual narration from the recording where it clarifies intent, impact, or reproduction steps. Quote short phrases from the transcript when they describe the problem, without inventing details that are not shown or said. Preserve timestamps when they help locate the problem in the recording.

Extract concrete visual evidence from the supplied material, including the affected UI states, actions, and keyframe timestamps where available. Distinguish the demonstrated problem from unrelated applications visible on screen. Remove unrelated screen clutter and obscure sensitive personal information without hiding details needed to reproduce the issue. Before delivery, verify the title matches the demonstrated problem, the steps follow the recording order, expected and actual results are clearly separated, and the issue reads cleanly.
