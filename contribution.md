# Contributing to ScreenContext

Issues are the best way to help shape ScreenContext. Bug reports, feature requests, ideas, and feedback are all welcome. You don’t need to write code to contribute.

[Open an issue](https://github.com/marcusschiesser/screencontext/issues/new) or [browse existing issues](https://github.com/marcusschiesser/screencontext/issues) to join a discussion. If someone has already reported your problem or suggested your idea, add your experience there.

## Reporting bugs

Tell us what you expected, what happened, and how to reproduce it. Include your macOS version and ScreenContext version. Screenshots or a short recording can help; remove any private information before sharing them.

## Ideas and feature requests

Describe what you’re trying to do and how ScreenContext could make it easier. Concrete examples help us understand the problem and decide what to work on next.

## Pull requests: bug fixes only

We accept pull requests for bug fixes only. For new features, redesigns, refactors, or other changes, please open an issue instead.

Keep a bug-fix PR focused on one problem. Link the relevant issue if there is one, explain the fix, and describe how you verified it. Add or update a regression test when practical, and follow the existing code style and native macOS design.

See the [README](README.md#build-and-test) for build and test commands and [design guidance](design.md) for UI conventions.

Thank you for helping make ScreenContext better.
