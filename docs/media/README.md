# ScreenContext media

ScreenContext brings screen recordings into AI-agent workflows and also works as an everyday screen recorder. It copies the video file or its local path, with an option to return to the app where recording started.

The existing GIFs, posters, and videos in this directory were produced for the earlier app and are **superseded**. They include removed template, keyframe, transcription, or HUD features. Do not use them for a new App Store submission.

The README hero uses the current Recordings window and the README’s AI-agent message, with a clean sample video and the native Swift compositor. Replacement icon artwork and video footage are in progress. The local review draft is `dist/app-store-review-2026-09-09/review.html`; its readiness document identifies remaining captures and artwork. The root README and its hero now describe the current app.

Current screenshot composition source: [render.swift](readme-hero-source/render.swift). Native UI captures are preserved without synthesizing interface elements.
